# leadglobe studio agents

Agent definitions adapted from [wshobson/agents](https://github.com/wshobson/agents) (MIT). Each one preloads specialist skills vendored in `.claude/skills/`; see each skill's `SOURCE.txt` and `LICENSE.upstream`. Every agent follows `_protocol.md`, which covers owner rules, mandatory skill use and the skill log the director verifies.

| Agent | Role |
|---|---|
| creative-director | concept, art direction, scored critique (no code) |
| editorial-typographer | type scale, rhythm, microtypography |
| motion-director | choreography and GSAP |
| webgl-engineer | three.js hero |
| frontend-engineer | builds approved concepts |
| design-system-steward | tokens and consistency |
| visual-qa | read-only QA with evidence |
